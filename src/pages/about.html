How this site is written

Each main project carries a status mark that says how real it is: a filled square for built and working, a half-filled square for working but not yet proven where it has to work, a hollow square for designed only, and a circle for simulation. Every number comes from my design records, logs or reports. Where something has not been built or tested yet, the page says so.
